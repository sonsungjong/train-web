# [11과목] 응용 SW 기초 기술 활용

## 1. 운영체제 (OS; Operating System)의 목적
사용자가 컴퓨터 하드웨어를 쉽게 사용할 수 있도록 인터페이스를 제공하는 소프트웨어입니다.
* **처리 능력 (Throughput) 향상:** 일정 시간 내에 시스템이 처리하는 일의 양.
* **반환 시간 (Turnaround Time) 단축:** 시스템에 작업을 의뢰한 시간부터 처리가 완료될 때까지 걸린 시간.
* **사용 가능도 (Availability) 향상:** 시스템을 얼마나 빠르게 사용할 수 있는지의 정도.
* **신뢰도 (Reliability) 향상:** 시스템이 주어진 문제를 얼마나 정확하게 해결하는지의 정도.

## 2. 프로세스 스케줄링 알고리즘 ★계산 문제 단골★
CPU를 사용하려고 하는 프로세스들 사이의 우선순위를 관리하는 작업입니다.

### 1) 비선점 (Non-Preemptive) 스케줄링
이미 할당된 CPU를 다른 프로세스가 강제로 빼앗을 수 없는 방식입니다.
* **FCFS (First Come First Service):** 준비상태 큐에 도착한 순서대로 CPU를 할당 (FIFO).
* **SJF (Shortest Job First):** 실행 시간이 가장 짧은 프로세스에게 먼저 CPU를 할당. (기아 현상 발생 가능)
* **HRN (Highest Response-ratio Next):** 실행 시간이 긴 프로세스에 불리한 SJF 기법을 보완하기 위해 대기 시간과 서비스 시간을 이용해 우선순위를 계산.
  * **우선순위 계산식:** `(대기 시간 + 서비스 시간) / 서비스 시간` (값이 클수록 우선순위가 높음)

### 2) 선점 (Preemptive) 스케줄링
하나의 프로세스가 CPU를 차지하고 있을 때, 우선순위가 높은 다른 프로세스가 현재 프로세스를 중단시키고 CPU를 빼앗을 수 있는 방식입니다.
* **Round Robin (RR):** 시간 할당량(Time Slice)을 정하여 그 시간 동안만 CPU를 사용하고, 완료되지 않으면 대기 큐의 가장 뒤로 배치.
* **SRT (Shortest Remaining Time):** 현재 실행 중인 프로세스의 남은 시간과 대기 큐에 새로 도착한 프로세스의 실행 시간을 비교하여 짧은 프로세스에게 CPU를 할당.
* **다단계 큐 (Multi-level Queue):** 프로세스들을 특정 그룹으로 분류할 수 있을 때, 그룹에 따라 여러 개의 큐를 두어 스케줄링.

## 3. 네트워크 OSI 7계층 ★매우 중요★
통신 접속에서 완료까지의 과정을 7단계로 정의한 국제 통신 표준 규약입니다.
*(암기 팁: 물·데·네·전·세·표·응)*

| 계층 | 이름 | 주요 기능 및 특징 | 대표 장비 / 프로토콜 |
| :--- | :--- | :--- | :--- |
| **1계층** | **물리 (Physical)** | 0과 1의 비트 스트림을 전기적 신호로 전송 | 리피터, 허브 |
| **2계층** | **데이터 링크 (Data Link)** | 노드 간의 신뢰성 있는 데이터 전송 보장, MAC 주소 사용 | 브릿지, 스위치 |
| **3계층** | **네트워크 (Network)** | 최적의 경로 설정 (Routing), 논리적 주소(IP) 사용 | 라우터, L3 스위치 / IP, ICMP |
| **4계층** | **전송 (Transport)** | 종단 간(End-to-End) 신뢰성 있는 데이터 전송, 오류 제어 및 흐름 제어 | 게이트웨이 / TCP, UDP |
| **5계층** | **세션 (Session)** | 통신 시스템 사용자 간의 연결을 유지 및 동기화 | SSH, TLS |
| **6계층** | **표현 (Presentation)** | 데이터의 압축, 암호화, 포맷 변환 수행 | JPEG, MPEG |
| **7계층** | **응용 (Application)** | 사용자가 네트워크에 접근할 수 있도록 서비스 제공 | HTTP, FTP, SMTP |

## 4. IP (Internet Protocol) 및 주요 통신 프로토콜
* **IPv4:** 32비트 주소 체계. 유니캐스트, 멀티캐스트, 브로드캐스트 방식 사용.
* **IPv6:** IPv4의 주소 고갈 문제를 해결하기 위한 128비트 주소 체계. 유니캐스트, 멀티캐스트, **애니캐스트(Anycast)** 방식 사용. 보안성 및 품질(QoS) 향상.
* **TCP (Transmission Control Protocol):** 연결 지향형, 신뢰성 보장, 순서 제어 기능 제공. (예: 파일 전송, 웹 브라우징)
* **UDP (User Datagram Protocol):** 비연결형, 신뢰성보다는 속도 중시. 헤더가 단순함. (예: 실시간 스트리밍, 온라인 게임)

## 5. 주요 라우팅 (Routing) 프로토콜
최적의 패킷 전송 경로를 설정하기 위한 통신 규약입니다.
* **RIP (Routing Information Protocol):** 거리 벡터(Distance Vector) 라우팅 프로토콜. 최대 홉(Hop) 수를 15로 제한하며, 소규모 네트워크에 적합. (벨만-포드 알고리즘 사용)
* **OSPF (Open Shortest Path First):** 링크 상태(Link State) 라우팅 프로토콜. 홉 수의 제한이 없고, 변화된 정보만 네트워크에 브로드캐스트하여 대규모 네트워크에 적합. (다익스트라 알고리즘 사용)
* **BGP (Border Gateway Protocol):** 자율 시스템(AS) 간의 라우팅 정보 교환을 위한 외부 라우팅 프로토콜(EGP).
