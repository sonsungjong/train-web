# [10과목] 프로그래밍 언어 활용

## 1. 연산자 (Operators)
* **산술 연산자:** `+`, `-`, `*`, `/` (몫), `%` (나머지)
* **증감 연산자:** `++x` (전위: 먼저 1 증가 후 연산), `x++` (후위: 연산 후 1 증가)
* **비트 연산자 (C, Java):** 데이터를 비트(0과 1) 단위로 연산. (16진수 변환 문제 단골)
    * `&` (AND): 두 비트가 모두 1일 때만 1.
    * `|` (OR): 둘 중 하나라도 1이면 1.
    * `^` (XOR): 두 비트가 서로 다를 때 1.
    * `~` (NOT): 0은 1로, 1은 0으로 반전.
    * `<<`, `>>` (Shift): 비트를 좌/우로 지정한 수만큼 이동.

## 2. 포인터와 배열 (C언어 핵심) ★매우 중요★
메모리 주소를 직접 다루는 C언어 특성상 포인터 문제는 매회 출제됩니다.

* **포인터 변수 (`*`):** 다른 변수의 '메모리 주소'를 저장하는 변수. (예: `int *ptr;`)
* **주소 연산자 (`&`):** 변수가 할당된 메모리의 시작 주소를 반환. (예: `ptr = &num;`)
* **참조 연산자 (`*`):** 포인터가 가리키는 주소에 저장된 '실제 값'을 반환. (예: `printf("%d", *ptr);`)
* **구조체 포인터 (`->`):** 구조체를 가리키는 포인터를 통해 구조체 내부의 멤버(변수)에 접근할 때 사용하는 화살표 연산자.
* **동적 메모리 할당:** 프로그램 실행 중에 메모리를 할당받고 반환하는 함수.
    * 할당: `malloc(sizeof(자료형) * 크기)`
    * 반환: `free(포인터변수)` (메모리 누수를 방지하기 위해 반드시 필요)

## 3. 객체지향 프로그래밍 (Java 핵심)

* **클래스(Class)와 객체(Object):** 클래스는 객체를 만들기 위한 설계도, 객체(인스턴스)는 설계도를 바탕으로 메모리에 구현된 실체.
* **생성자 (Constructor):** 객체가 생성될 때 가장 먼저 호출되어 초기화를 담당하는 특별한 메서드. (클래스 이름과 동일하며 반환 타입이 없음)
* **상속 (Inheritance):** 부모 클래스의 멤버를 자식 클래스가 물려받는 것. Java에서는 `extends` 키워드 사용.
* **오버로딩 (Overloading):** 같은 이름의 메서드를 **매개변수의 타입이나 개수를 다르게** 하여 여러 개 정의하는 기법.
* **오버라이딩 (Overriding):** 상속받은 부모 클래스의 메서드를 **자식 클래스에서 재정의(수정)**하여 사용하는 기법.

## 4. 예외 처리 (Exception Handling)
프로그램 실행 중 예기치 못한 오류가 발생했을 때 프로그램이 강제 종료되지 않도록 처리하는 구문입니다.
* **구조:** `try` (실행할 코드) ➔ `catch` (예외 발생 시 처리할 코드) ➔ `finally` (예외 발생 여부와 상관없이 무조건 마지막에 실행할 코드)
* **주요 예외 종류 (Java):**
    * `ArithmeticException`: 0으로 나누는 등 산술적인 오류.
    * `ArrayIndexOutOfBoundsException`: 배열의 인덱스 범위를 벗어난 접근.
    * `NullPointerException`: 생성되지 않은 객체(Null)를 참조하려고 할 때.

## 5. 파이썬 (Python) 특화 자료형 및 문법
C나 Java와 다른 파이썬만의 독특한 문법과 자료구조가 자주 출제됩니다.
* **리스트 (List):** `[1, 2, 3]` (순서 O, 중복 O, 값 변경 O) - 슬라이싱(`a[1:3]`) 기능 숙지.
* **튜플 (Tuple):** `(1, 2, 3)` (순서 O, 중복 O, **값 변경 불가능**)
* **세트 (Set):** `{1, 2, 3}` (**순서 X, 중복 X**) - 수학의 집합 연산과 동일. `&`(교집합), `|`(합집합), `-`(차집합)
* **딕셔너리 (Dictionary):** `{'key': 'value'}` (키와 값의 쌍으로 구성, **키는 중복 불가능**)
