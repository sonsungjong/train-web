# 정보처리기사 실기 요약 노트: [9과목] 소프트웨어 개발 보안 구축

## 1. 정보 보안의 3대 요소 (CIA Triad) ★매우 중요★
*(암기 팁: 기·무·가)*
* **기밀성 (Confidentiality):** 인가된 사용자만 정보 자산에 접근할 수 있음. (방화벽, 암호화)
* **무결성 (Integrity):** 인가된 사용자만 정보를 수정할 수 있으며, 정보가 전송 중에 변조되지 않았음을 보장. (해시 함수, 디지털 서명)
* **가용성 (Availability):** 인가된 사용자는 언제든지 필요할 때 정보 자산에 접근하여 사용할 수 있음. (데이터 백업, 이중화)

## 2. Secure SDLC (안전한 소프트웨어 개발 생명주기)
보안상 안전한 소프트웨어를 개발하기 위해 SDLC에 보안 강화를 위한 프로세스를 포함한 것을 의미합니다.
* **Seven Touchpoints:** 소프트웨어 개발 생명주기의 각 단계에 관련된 7가지의 보안 강화 활동을 개발자에게 집중적으로 관리하도록 요구하는 방법론.
* **MS SDL (Microsoft Secure Development Lifecycle):** 마이크로소프트사에서 안전한 소프트웨어를 개발하기 위해 자체 수립한 방법론.
* **CLASP (Comprehensive Lightweight Application Security Process):** '활동 중심', '역할 기반'의 프로세스로, 현재 운영 중인 시스템에 적용하기 쉬운 보안 개발 방법론.

## 3. 주요 네트워크 공격 기법 (DoS / DDoS)
시스템을 악의적으로 공격해서 해당 시스템의 자원을 부족하게 하여 원래 의도된 용도로 사용하지 못하게 하는 공격입니다.
* **Ping of Death (죽음의 핑):** 정상 크기보다 아주 큰 핑(Ping) 패킷을 보내어 네트워크를 마비시키는 공격.
* **Smurfing (스머핑):** IP나 ICMP의 특성을 악용하여 엄청난 양의 데이터를 한 사이트에 집중적으로 보내어 네트워크를 마비시키는 공격.
* **SYN Flooding:** TCP의 3-Way Handshake 취약점을 이용하여, 서버의 동시 가용 사용자 수를 꽉 차게 만들어 정상적인 접속을 불가능하게 하는 공격.
* **TearDrop (티어드롭):** IP 패킷의 분할 순서(Fragment Offset) 값을 조작하여 수신 측에서 재조립 시 오류와 과부하를 유발하는 공격.
* **Land Attack (랜드 어택):** 패킷을 전송할 때 출발지 IP 주소와 목적지 IP 주소를 똑같이 만들어서, 수신자가 자기 자신에게 응답을 보내게 하여 시스템을 무한 루프에 빠뜨리는 공격.

## 4. 주요 웹 애플리케이션 공격 기법 ★매우 중요★
* **SQL Injection (SQL 삽입):** 웹 페이지의 입력 폼 등에 악의적인 SQL 구문을 삽입하여 데이터베이스를 비정상적으로 조작하는 공격.
* **XSS (Cross-Site Scripting, 크로스 사이트 스크립팅):** 게시판 등에 악성 스크립트를 삽입하여, 해당 글을 읽는 사용자의 브라우저에서 스크립트가 실행되게 하여 정보(쿠키, 세션 등)를 빼내는 공격.
* **CSRF (Cross-Site Request Forgery, 크로스 사이트 요청 위조):** 사용자가 자신의 의지와는 무관하게 공격자가 의도한 행위(수정, 삭제, 등록 등)를 특정 웹사이트에 요청하게 만드는 공격.
* **Ransomware (랜섬웨어):** 컴퓨터 내의 문서나 파일을 암호화하여 사용하지 못하게 한 뒤, 암호 해독용 키를 빌미로 금전을 요구하는 악성 프로그램.
* **Zero Day Attack (제로 데이 공격):** 보안 취약점이 발견되었을 때 널리 공표되기도 전에, 혹은 패치가 배포되기 전에 해당 취약점을 이용하여 이루어지는 보안 공격.

## 5. 서버 접근 통제 (Access Control) 기법
사용자(주체)가 시스템(객체)에 접근하는 것을 제어하는 방식입니다.
* **DAC (Discretionary Access Control, 임의 접근 통제):** 데이터에 접근하는 사용자의 **신원(Identity)**에 따라 권한을 부여. (데이터 소유자가 권한을 지정)
* **MAC (Mandatory Access Control, 강제 접근 통제):** 주체와 객체의 **보안 등급(Label)**을 비교하여 권한을 부여. (시스템/관리자가 권한을 지정)
* **RBAC (Role Based Access Control, 역할 기반 접근 통제):** 사용자의 **역할(Role)**에 따라 권한을 부여. 인사 이동이 잦은 조직에 적합.
